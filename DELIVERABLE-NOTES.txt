====================================================================
 TgMini + TgMiniSetupDriver  —  портативный «мини-Телеграм»
====================================================================

ЧТО ЭТО
  Папка содержит упрощённый клиент Telegram (TgMini.exe) и вспомогательный
  драйвер (TgMiniSetupDriver.exe), который при первом запуске автоматически
  заполняет окно «Первый запуск» (API ID / API Hash / Телефон) и сохраняет
  config.toml.

  ВАЖНО: в этой сборке НЕТ никаких чужих/заранее вшитых учётных данных.
  Каждый пользователь вводит СВОИ api_id, api_hash и телефон.

ТРЕБОВАНИЯ
  Windows 10/11 x64 и установленный .NET 9 Desktop Runtime
  (Microsoft.WindowsDesktop.App):
      https://dotnet.microsoft.com/download/dotnet/9.0
  Проверить наличие:  dotnet --list-runtimes   (должна быть строка
  Microsoft.WindowsDesktop.App 9.x)

СПОСОБ 1 — ВРУЧНУЮ (без драйвера)
  1) Запустите TgMini.exe.
  2) В окне «Первый запуск» введите свои API ID, API Hash и телефон.
     Получить ключи: https://my.telegram.org -> API development tools.
  3) Нажмите «Сохранить и продолжить».
  Конфиг сохраняется в:  %LOCALAPPDATA%\TgMini\config.toml

СПОСОБ 2 — АВТОМАТИЧЕСКИ (драйвер сам заполнит и сохранит)
  Учётные данные подаются ТОЛЬКО извне, тремя способами (приоритет сверху вниз):

  1) Аргументы командной строки:
       TgMiniSetupDriver.exe --apiid 1234567 --apihash <32_символа> --phone +79001234567

  2) JSON-файл:
       copy creds.example.json creds.json      (и впишите свои значения)
       TgMiniSetupDriver.exe --config creds.json

  3) Переменные окружения:
       set TGMINI_APIID=1234567
       set TGMINI_APIHASH=<32_символа>
       set TGMINI_PHONE=+79001234567
       TgMiniSetupDriver.exe

  Полезные опции:
       --app <путь>     путь к TgMini.exe (по умолчанию — рядом с драйвером)
       --config <путь>  путь к config.toml (по умолчанию %LOCALAPPDATA%\TgMini\config.toml)
       --no-launch      не запускать TgMini (окно уже открыто)
       --no-verify      не проверять config.toml после сохранения
       --help           помощь

  Коды выхода: 0 — успех; 1 — ошибка/неверное использование.

ПРИМЕЧАНИЯ
  * Драйвер управляет окном через UI Automation, поэтому запускайте его в
    той же пользовательской сессии, что и TgMini (не как службу).
  * Никакие данные не передаются наружу самим драйвером — он только
    вводит то, что вы ему передали, в окно TgMini.
