# TgMini — Memory & Knowledge Base

Документ постоянной памяти проекта: архитектура, ключевые решения и история исправленных ошибок.

## 1. О проекте и стек
- **Название**: TgMini (Portable Clean Telegram Desktop Client)
- **Стек**: C# 13, .NET 9, WPF, WTelegramClient, MVVM
- **Основная цель**: Легковесный, чистый, переносимый мини-клиент Telegram без лишнего оверхеда официального десктопа.

## 2. Архитектура и принципы
- **Чистый репозиторий**: Все сессии (`*.session`), конфигурации с API ID/Hash вынесены наружу и никогда не коммитятся.
- **Современный .NET 9**: Использование `sealed class`, primary constructors, memory optimization, асинхронные потоки.
- **UI**: Кастомный тёмный WPF UI с плавным скроллом и адаптивной версткой.

## 4. База знаний ошибок и фиксов (Post-mortem)
- **WTelegramClient flood wait**: При частых запросах диалогов обязательно ловить `RpcException` и выдерживать рекомендованную задержку.
- **WPF Threading**: Обновление коллекций `ObservableCollection` должно происходить строго через `Dispatcher.InvokeAsync` или `BindingOperations.EnableCollectionSynchronization`.
